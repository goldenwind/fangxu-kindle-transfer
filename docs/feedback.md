# 方序传书产品反馈

- 产品名称：方序传书
- 产品 ID：`11`
- 产品标识：`fangxu_kindle_transfer`
- 反馈地址：<https://api.ip21.cn/products/11/feedback>

客户端侧栏的“产品反馈”在软件内打开独立的原生 WebView 窗口，直接展示上述产品页面。重复点击会恢复并聚焦已有窗口，不刷新页面，保留正在填写的内容。关闭反馈窗口不影响主窗口和传书服务；再次打开会重新加载页面。反馈沿用现有公众号登录流程，登录仅用于反馈，局域网传书无需账号。反馈类型按接口文档统一为功能故障（`bug`）、功能建议（`feature`）、登录与购买（`login_purchase`）、其他反馈（`other`）。

## 软件环境

接入协议见 [`gf_api/docs/product_feedback.md`](../../../gitee.com/gf_api/docs/product_feedback.md)。桌面端点击反馈入口时读取当前软件和系统信息，通过 URL 片段携带四个字段：

| 字段 | 来源 | 最大字符数 |
| --- | --- | --- |
| `app_version` | 当前 Tauri 应用版本（`tauri.conf.json`） | 64 |
| `os` | 原生运行平台：`macos`、`windows`、`linux` | 32 |
| `os_version` | `os_info` 读取的系统版本；读取不到时省略 | 128 |
| `arch` | `os_info` 读取的系统架构；读取不到时使用客户端编译架构 | 32 |

所有值先去除首尾空格并按字符数截断，再按 URL 表单参数编码。例如：

```text
https://api.ip21.cn/products/11/feedback#app_version=0.2.0&os=macos&os_version=15.6.1&arch=arm64
```

反馈页读取后立即清除片段，将环境信息显示在表单中，并在用户提交反馈时原样提交。登录状态由反馈页在客户端 WebView 内保存，首次使用需要完成公众号登录，不共享系统浏览器的登录状态。环境读取和打开反馈窗口独立于传书服务，服务启动中或异常时仍可反馈。浏览器开发预览保留普通反馈链接，不推断客户端系统信息。

反馈页直接使用自己的 HTTPS 来源，支持登录请求、二维码图片和截图文件选择，无需 iframe 或放宽主界面的 CSP。原生能力仍只授权给 `main` 窗口，反馈窗口没有传书服务、文件系统或剪贴板的原生权限。窗口创建与系统信息检测在后台线程执行，兼容 Windows 的 WebView 创建要求。

反馈入口只携带上述软件环境信息，不收集本地电子书、传书目录或日志。字段编码、长度限制及缺少系统版本的兼容性由 `cargo test --manifest-path src-tauri/Cargo.toml feedback::tests` 验证。
